BLUE OX VENDING - MACHINE LOCATOR
=================================

Finds businesses around Oklahoma City worth putting a machine in,
and writes the emails to them.

It runs on this computer. It is free. Nothing is uploaded anywhere.


TO START IT
-----------

  WINDOWS
     Double-click       Machine Locator.bat

     If a blue box says "Windows protected your PC":
        click  More info,  then  Run anyway.

     If it says Python is missing, it will offer to install it for
     you. Say Y. When it finishes, CLOSE the window and double-click
     Machine Locator again.

  MAC
     RIGHT-CLICK        Machine Locator.command      and choose Open.
     Then click Open again when it asks.

     Use right-click the FIRST time, not a double-click. macOS blocks
     downloaded files that are double-clicked.


WHAT HAPPENS
------------

A black window opens. The first time it spends about a minute setting
itself up. Then your web browser opens with the app in it.

LEAVE THE BLACK WINDOW OPEN while you use it. Closing it stops the
app. Nothing is lost - your work is saved as you go.

To stop:  close the black window.
To start again:  same as above. It is quick after the first time.


IF NOTHING HAPPENS
------------------

  * Is this folder still inside the zip file you downloaded?
    Right-click the zip, choose "Extract All", and open the folder
    that comes out. It cannot set itself up inside a zip.

  * Did a blue "Windows protected your PC" box appear?
    Click More info, then Run anyway.


FIRST THREE THINGS TO DO IN THE APP
-----------------------------------

  1. Click  Find prospects.  Takes 2-3 minutes. Finds and ranks
     around 400 Oklahoma City businesses.

  2. Go to  Settings.  Blue Ox Vending and your phone number are
     already filled in. Add your mailing address and your email
     address, then click Test connection.

     For Gmail you need an "App Password", not your normal one:
     https://myaccount.google.com/apppasswords

  3. Send one test email TO YOURSELF before emailing any real
     business. README.md explains how.


USING IT ON AN IPAD OR PHONE
----------------------------

There is a second launcher for that - "Machine Locator on iPad".
Your computer has to stay on and both devices on the same Wi-Fi.

It prints a web address and a QR code. Point the iPad camera at the
code, or type the address into Safari.

Say ALLOW if your computer asks about incoming connections - the
iPad cannot reach it otherwise. If the iPad still shows a blank
page, read the launcher window: it checks whether the iPad can
actually reach this computer and prints what to fix.

See README.md.
